# Kingsfit Edwin — Personal Website & Buying Guides

A responsive static website for a personal brand and general product recommendation content.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `kingsfit-site`.
2. Upload `index.html` and the `assets` folder to the repository's root (not inside another folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait a few minutes for the published URL shown in Settings → Pages.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with a public contact email.
- Review the About section and make sure it accurately represents you.
- The affiliate disclosure contains a template note. Do not claim to be an Amazon Associate until accepted into the program; update the notice to meet the rules of the Amazon marketplace you join.
- The buying-guide content is a starter draft. Improve it with your own experience, original comparisons, photographs, and specific product research before applying. Do not add affiliate links to products you have not checked.
- This starter site does not contain Amazon product links and does not guarantee acceptance into Amazon Associates.
